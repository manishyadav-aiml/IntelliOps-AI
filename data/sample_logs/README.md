# Sample logs (synthetic)

These files are **synthetic**, generated by `scripts/generate_sample_logs.py` (seed 42). They are not real production logs; hosts, IPs (documentation ranges) and users are invented.

| File | Content |
|------|---------|
| `normal_activity.log` | Normal gateway/auth/payment traffic with occasional slow-query warnings |
| `incident_payment_failure.log` | Normal traffic, then database timeouts, payment failures, API latency, circuit breaker/service unavailable, network refusals, a memory warning |
| `auth_failures.csv` | CSV with a burst of failed authentications |

Regenerate with `python scripts/generate_sample_logs.py`.
